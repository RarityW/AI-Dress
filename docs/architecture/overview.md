# 架构概览

衣见 AI 采用前后端分离架构。

## 数据流向
1. **AI Perception (AI 感知)**: 多模态视觉模型对衣物进行识别与特征提取。
2. **Structured Data (结构化数据)**: 将提取特征存入数据库。
3. **Recommendation Engine (推荐引擎)**: 结合用户偏好、天气与穿搭历史，生成建议。
4. **Ranked Results (排序结果)**: 输出穿搭榜单至前端。

## 组件
- **前端**: SPA 应用提供用户交互界面。
- **后端 API**: FastAPI 提供核心业务逻辑与模型交互。
- **持久化层**: 结构化数据与图片资源存储。
